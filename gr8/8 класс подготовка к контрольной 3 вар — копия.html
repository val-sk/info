Логическое высказывание

Повествовательное предложение, о котором можно однозначно сказать, истинно оно или ложно.
✅ «Число 6 чётное» — высказывание (истина). ❌ «Который час?», «Откройте учебник», «x + 5 > 10» — не высказывания.

Истина обозначается 1, ложь — 0.

Основные операции

AB¬AA ∧ B (И)A ∨ B (ИЛИ)A → B
001001
011011
100010
110111
  • Конъюнкция (И, ∧) — истинна, только когда истинны оба высказывания.
  • Дизъюнкция (ИЛИ, ∨) — ложна, только когда оба ложны.
  • Отрицание (НЕ, ¬) — меняет значение на противоположное.
  • Импликация (→) — «если A, то B»; ложна только при A = 1, B = 0. Равносильна ¬A ∨ B.

Порядок действий

Скобки → ¬ → ∧ → ∨ → →.

Задания ОГЭ «числа и логика» — алгоритм

  1. Переведи словесные условия в логику: «x чётное» → x mod 2 = 0; «сумма цифр делится на 3» и т.п.
  2. Раскрой НЕ: НЕ (P ИЛИ Q) = (НЕ P) И (НЕ Q); НЕ (x ≥ a) = x < a.
  3. Для «сколько чисел» — найди диапазон и посчитай подходящие по порядку.
  4. Для «наибольшее / наименьшее» — выпиши диапазон и возьми крайний подходящий элемент.

Как строить таблицу истинности

  1. Число строк = 2n: 2 переменные → 4 строки, 3 → 8 строк.
  2. Наборы значений — в порядке возрастания двоичных чисел: 00, 01, 10, 11.
  3. Столбцы промежуточных действий — по порядку операций, затем итоговый столбец F.
