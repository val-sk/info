01 · Пример из жизни

Зачем нужны бинарные деревья?

Плей-офф любого турнира — это полное бинарное дерево: каждая игра порождает ровно двух участников следующей стадии, а корень — финал. Алгоритм «провести сетку» идентичен обходу дерева от листьев к корню.

Турнирная сетка на 8 команд

Листья — команды, внутренние узлы — матчи, корень — чемпион. Золотая линия — путь победителя от листа к корню.

Код Хаффмана

Архиваторы ZIP и аудиокодеры строят бинарное дерево частот символов — так файлы сжимаются без потерь.

Деревья решений

Банк решает «дать ли кредит», врач — диагноз: на каждом шаге вопрос с двумя ответами «да/нет» — бинарное ветвление.

Файловая система

Каталог содержит подкаталоги и файлы — дерево. Путь C:\учёба\информатика\дз — маршрут от корня к листу.

Родословные

Генеалогическое дерево — классическая иерархия: у каждой записи не более двух родителей и сколько угодно детей.

Вывод: дерево — это иерархия, а бинарное дерево — иерархия, где у каждого элемента не более двух «ветвей». Дальше — строгие определения и реализация.

02 · Теория

Что такое дерево. Ссылочная реализация

Дерево — иерархическая структура из узлов, соединённых рёбрами: один узел объявляется корнем, а каждый остальные имеет ровно одного родителя. Реализуется дерево ссылками: узел хранит данные и адреса своих потомков.

Наведите на термин — дерево подсветит его

Кореньединственный узел без родителя — вершина иерархии (A)
Внутренний узелузел, у которого есть потомки (B, C)
Листузел без потомков (D, E, F, G)
Ребросвязь «родитель → потомок»; в дереве из N узлов ровно N−1 ребро
Уровеньрасстояние узла от корня в рёбрах; корень — на уровне 0
Высотадлина самого длинного пути от корня до листа

Как узел устроен в памяти

Дерево — рекурсивная структура: каждый потомок сам является корнем поддерева. Поэтому почти все алгоритмы на деревьях — рекурсивны.

03 · Теория

Двоичные (бинарные) деревья

Бинарное дерево — дерево, в котором у каждого узла не более двух потомков, причём различаются левый и правый (поменять местами — получится другое дерево).

Какие бывают

Свойства полного бинарного дерева

На уровне k максимум 2ᵏ узлов
Всего узлов при высоте h: 2h+1 − 1
Листьев при высоте h: 2ʰ
Внимание: если узлы вставлять в отсортированном порядке, дерево вырождается в список — высота N вместо log₂N, и поиск снова становится линейным.

Дерево двоичного поиска (ДДП / BST)

Особый вид бинарного дерева: слева от узла — значения меньше, справа — больше. Благодаря этому поиск работает за O(log n): на каждом шаге отбрасываем половину.

04 · Теория + живой инструмент

Дерево арифметического выражения

Листья — операнды (числа), внутренние узлы — операции. Корень — операция, которая выполняется последней. Строится рекурсивно: находим главную операцию → левый операнд уходит в левое поддерево, правый — в правое.

1 главная операция
(3 + 5) * (9 − 4)

Вне скобок только «*» — она выполняется последней и становится корнем.

2 левое поддерево
(3 + 5)

Главная операция операнда — «+». Её операнды 3 и 5 становятся листьями.

3 правое поддерево
(9 − 4)

Аналогично: «−» — узел, 9 и 4 — листья. Дерево готово, можно вычислять снизу вверх.

08 · Разработка программы

Вычислитель выражений на Python

Соберём программу из трёх шагов: класс узла → построение дерева «снизу вверх» → рекурсивное вычисление. Задача: вычислить (2 + 3) * (9 − 4).

1

Узел — ссылочная структура

Значение + две ссылки на потомков. None — потомка нет.

ШАГ 1 · узел
class Node:
    def __init__(self, value, left=None, right=None):
        self.value = value   # число или знак операции
        self.left  = left    # ссылка на левое поддерево
        self.right = right   # ссылка на правое поддерево
2

Строим дерево для (2 + 3) * (9 − 4)

Сначала листья, потом их «родители», последним — корень. Читается как вложенные скобки.

ШАГ 2 · построение
plus  = Node('+', Node(2), Node(3))   # левое поддерево: 2 + 3
minus = Node('-', Node(9), Node(4))   # правое поддерево: 9 - 4
tree  = Node('*', plus, minus)        # корень: (2+3) * (9-4)
3

Вычисляем обходом в глубину

Лист возвращает число; узел рекурсивно вычисляет детей и применяет операцию.

ШАГ 3 · вычисление
def evaluate(t):
    if t.left is None and t.right is None:
        return t.value              # лист: просто число
    l = evaluate(t.left)            # результат левого поддерева
    r = evaluate(t.right)           # результат правого поддерева
    if t.value == '+': return l + r
    if t.value == '-': return l - r
    if t.value == '*': return l * r
    if t.value == '/': return l / r

print("Результат:", evaluate(tree))

Полная программа одним файлом

expr_tree.py
# Дерево арифметического выражения
class Node:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left  = left
        self.right = right

def evaluate(t):
    if t.left is None and t.right is None:
        return t.value
    l = evaluate(t.left)
    r = evaluate(t.right)
    if t.value == '+': return l + r
    if t.value == '-': return l - r
    if t.value == '*': return l * r
    if t.value == '/': return l / r

# строим:  (2 + 3) * (9 - 4)
tree = Node('*',
        Node('+', Node(2), Node(3)),
        Node('-', Node(9), Node(4)))

print("Результат:", evaluate(tree))   # 25

Бонус: постфиксная запись

Тот же обход, только вместо вычисления собираем строку — получаем запись без скобок, понятную стековой машине.

postfix.py
def postfix(t):
    if t.left is None and t.right is None:
        return str(t.value)
    return postfix(t.left) + " " + \
           postfix(t.right) + " " + t.value

print(postfix(tree))   # 2 3 + 9 4 - *

Три задания на разработку программ

Используйте класс Node из предыдущего шага. Каждое задание сдаётся работающим файлом .py с комментариями.

П1

Дерево и результат

★☆☆базовый

Постройте ссылочное дерево для выражения 3 * (2 + 8) и вычислите его функцией evaluate(t).

  • создайте узлы-листья 2, 8, 3 отдельными переменными;
  • соберите дерево «снизу вверх»;
  • выведите результат на экран.
Ожидаемый вывод: Результат: 30
Подсказка
Корень — операция «*» (выполняется последней). Её правый ребёнок — поддерево «+» с листьями 2 и 8, левый — лист 3.
П2

Обходы дерева

★★☆средний

Для дерева выражения (5 - 2) * 4 напишите три функции обхода: infix(t), prefix(t), postfix(t) — и выведите все три записи.

  • infix — левое поддерево, узел, правое поддерево;
  • prefix — узел, левое, правое;
  • postfix — левое, правое, узел.
Ожидаемый вывод: * - 5 2 4  ·  5 2 - 4 *  ·  инфиксная запись может содержать скобки
Подсказка
Все три обхода отличаются только тем, в какой момент печатается сам узел: до, между или после рекурсивных вызовов детей.
П3

Защита от ошибок

★★★продвинутый

Возьмите программу из П1 и доработайте: вычислите выражение 10 / (5 - 5) так, чтобы программа не падала, а выводила понятное сообщение.

  • используйте try / except ZeroDivisionError при вызове evaluate;
  • при ошибке выведите «Ошибка: деление на ноль»;
  • дополнительно (на «5»): запрашивайте числа листьев через input().
Ожидаемый вывод: Ошибка: деление на ноль
Подсказка
Оборачивайте не саму рекурсию, а итоговый вызов: try: print(evaluate(tree)) except ZeroDivisionError: print(...) — исключение «всплывёт» из глубины дерева само.

10 · Итоги

Что запоминаем

Дерево — иерархия узлов: корень, родители, потомки, листья; у листа степень 0.
Ссылочная реализация: узел = данные + ссылки на потомков; у листа ссылки равны None.
В бинарном дереве у узла не более двух детей, левый и правый различаются.
Дерево выражения: листья — числа, узлы — операции, корень — последняя операция.
Обход в глубину одновременно и вычисляет выражение, и даёт пре-/постфиксную запись.
