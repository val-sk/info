Построение минимального остовного дерева

Взвешенный связный неориентированный граф: от идеи — до программы на Python.

В. Г. Соловьянюк-Кротова · АНО «Павловская гимназия» · val-sk.github.io/info

Зелёные рёбра — минимальное остовное дерево этого графа. Почему именно они — выясним на уроке.

Шаг 1 · Разминка

Вспомним теорию графов

Сначала ответь вслух — потом нажми на карточку и проверь себя.

?Что такое граф?
Набор вершин и рёбер, соединяющих пары вершин. Граф моделирует связи между объектами: города и дороги, компьютеры и кабели.
?Чем неориентированный граф отличается от ориентированного?
У неориентированного графа рёбра без направления: связь работает «в обе стороны», A–B — то же самое, что B–A.
?Что такое взвешенный граф?
Граф, в котором каждому ребру приписано число — вес: длина, стоимость, время, пропускная способность.
?Что такое связный граф?
Граф, в котором из любой вершины есть путь в любую другую. Никаких «оторванных островков».
?Что такое цикл?
Путь, который начинается и заканчивается в одной вершине и не повторяет рёбра. «Круговой маршрут».
?Что такое дерево? Сколько в нём рёбер?
Связный граф без циклов. В дереве с n вершинами ровно n − 1 ребро — ни больше, ни меньше.
Всё вспомнили? Теперь соберём из этих понятий новое — «минимальное остовное дерево».
Шаг 1 · Новое понятие

Что такое минимальное остовное дерево?

Остовное дерево графа — подграф, который содержит все вершины и является деревом (связный, без циклов).
Минимальное остовное дерево (МОД) — остовное дерево с наименьшей суммой весов рёбер.
🌐 все вершины графа🔗 ровно n − 1 ребро 🚫 нет циклов⚖️ сумма весов минимальна

Просто остовное дерево

вес 23

Минимальное остовное дерево

вес 18

Оба дерева связывают все 6 вершин, но справа — дешевле на 5. Как найти самое дешёвое — и есть наша задача.

Если все веса различны — МОД единственное. При равных весах деревьев-МОД может быть несколько, но минимальная сумма всегда одна.

Шаг 3 · Алгоритм

Алгоритм Краскала (Kruskal): жадно, но аккуратно

Идея: перебираем рёбра от самых дешёвых и берём каждое, если оно не создаёт цикл. Почему это работает: самое лёгкое ребро между двумя частями графа всегда «безопасно» — существует МОД, которое его содержит. Жадность не ошибается.

1️⃣ Отсортировать

Все рёбра — по возрастанию веса.

2️⃣ Каждая вершина — отдельная команда

В начале каждая вершина — своя компонента связности.

3️⃣ Идём по списку

Концы ребра в разных компонентах → берём ребро и объединяем команды.
Концы уже в одной компоненте → пропускаем: будет цикл.

4️⃣ Стоп на n − 1

Набрали n − 1 ребро — дерево готово, дальше можно не смотреть.
Альтернатива — алгоритм Прима: растим одно дерево из стартовой вершины, каждый раз добавляя самое дешёвое ребро, у которого ровно один конец уже в дереве. Результат тот же — МОД.
Скорость: самая дорогая часть Краскала — сортировка: O(E·log E), где E — число рёбер.

Представляем граф в программе

Вершины пронумеруем от 0 до n − 1, имена сохраним в списке names. Каждое ребро — список из трёх чисел [u, v, вес]. Все рёбра — список списков. Никаких классов, кортежей и словарей — только списки!

данные графа
names = ["A", "B", "C", "D", "E", "F"]
n = 6

# ребро = [номер u, номер v, вес]
edges = [
    [0, 1, 3],   # A-B
    [0, 2, 5],   # A-C
    [1, 2, 1],   # B-C
    [1, 3, 6],   # B-D
    [2, 3, 4],   # C-D
    [2, 4, 2],   # C-E
    [3, 4, 7],   # D-E
    [3, 5, 8],   # D-F
    [4, 5, 9],   # E-F
]
0 → A1 → B2 → C 3 → D4 → E5 → F
Почему список, а не кортеж? Список можно изменять, и он нам уже знаком. Ребро [1, 2, 1] — это B–C весом 1.
Шаг 4 · Код · 2 из 5

Сортируем рёбра по весу

Метод sort умеет сортировать по «ключу». Напишем функцию weight, которая возвращает третий элемент ребра, и передадим её: key=weight. Python сам вызовет её для каждого ребра.

сортировка
# ключ сортировки — вес ребра (третий элемент)
def weight(edge):
    return edge[2]

edges.sort(key=weight)
🔎 Что получится после сортировки?нажми
B–C · 1C–E · 2A–B · 3 C–D · 4A–C · 5B–D · 6 D–E · 7D–F · 8E–F · 9

От лёгких к тяжёлым — именно в таком порядке будем рассматривать рёбра.

Передаём именно функцию weight, без скобок: sort сам будет её вызывать. weight(edge) со скобками — это уже вызов, так делать не надо.
Шаг 4 · Код · 3 из 5

Компоненты связности: «команды и капитаны»

Как понять, что ребро создаёт цикл? Его концы уже в одной компоненте! Заведём список parent: parent[v] — «родитель» вершины v. Сначала каждая вершина — капитан самой себя. find(v) поднимается по родителям до капитана (корня).

parent и find
# сначала каждая вершина — "капитан" самой себя
parent = []
for i in range(n):
    parent.append(i)

# поднимаемся по родителям до капитана (корня)
def find(v):
    while parent[v] != v:
        v = parent[v]
    return v
🔎 Что лежит в parent после рёбер B–C, C–E, A–B?нажми
parent = [4, 2, 4, 3, 4, 5]

A(0) → E(4), B(1) → C(2) → E(4), C(2) → E(4). Капитан команды {A, B, C, E} — E. D и F пока сами себе капитаны.

Главное правило: две вершины в одной компоненте ⇔ find(u) == find(v).
Шаг 4 · Код · 4 из 5

Объединение и главный цикл

union «подвешивает» команду a к капитану команды b. Главный цикл — сердце Краскала: берём ребро, только если концы в разных командах; набрали n − 1 ребро — выходим.

union + главный цикл
# объединяем команды: капитан a подчиняется капитану b
def union(a, b):
    root_a = find(a)
    root_b = find(b)
    parent[root_a] = root_b

# главный цикл Краскала
mst = []
total = 0
for edge in edges:
    u = edge[0]
    v = edge[1]
    w = edge[2]
    if find(u) != find(v):     # цикла не будет — берём
        union(u, v)
        mst.append(edge)
        total = total + w
        if len(mst) == n - 1:  # набрали n-1 ребро — готово
            break
Строка if find(u) != find(v) — это и есть проверка «не будет ли цикла». А break — досрочная победа: дерево уже готово, лишние рёбра можно не смотреть.
Шаг 4 · Код · 5 из 5

Выводим ответ буквами

В mst лежат рёбра-списки с индексами. Превратим индексы обратно в имена: names[edge[0]]. Сумма весов уже посчитана в total.

вывод
print("Рёбра минимального остовного дерева:")
for edge in mst:
    print(names[edge[0]], "-", names[edge[1]], "вес", edge[2])
print("Суммарный вес:", total)
print с запятыми ставит пробелы между аргументами — удобно для простого отчёта.
Шаг 4 · Всё вместе

Полная программа

kruskal.py 
# Минимальное остовное дерево — алгоритм Краскала
# Только списки, циклы, условия и функции

# 1. Данные: имена вершин и рёбра [u, v, вес]
names = ["A", "B", "C", "D", "E", "F"]
n = 6
edges = [
    [0, 1, 3],   # A-B
    [0, 2, 5],   # A-C
    [1, 2, 1],   # B-C
    [1, 3, 6],   # B-D
    [2, 3, 4],   # C-D
    [2, 4, 2],   # C-E
    [3, 4, 7],   # D-E
    [3, 5, 8],   # D-F
    [4, 5, 9],   # E-F
]

# 2. Сортируем рёбра по весу
def weight(edge):
    return edge[2]

edges.sort(key=weight)

# 3. Компоненты связности: список родителей и поиск корня
parent = []
for i in range(n):
    parent.append(i)

def find(v):
    while parent[v] != v:
        v = parent[v]
    return v

def union(a, b):
    root_a = find(a)
    root_b = find(b)
    parent[root_a] = root_b

# 4. Главный цикл: берём лёгкие рёбра без циклов
mst = []
total = 0
for edge in edges:
    u = edge[0]
    v = edge[1]
    w = edge[2]
    if find(u) != find(v):     # цикла не будет — берём
        union(u, v)
        mst.append(edge)
        total = total + w
        if len(mst) == n - 1:  # дерево готово
            break

# 5. Вывод результата
print("Рёбра минимального остовного дерева:")
for edge in mst:
    print(names[edge[0]], "-", names[edge[1]], "вес", edge[2])
print("Суммарный вес:", total)
вывод программы
Рёбра минимального остовного дерева:
B - C вес 1
C - E вес 2
A - B вес 3
C - D вес 4
D - F вес 8
Суммарный вес: 18
В программе только списки, циклы, условия и функции — ни классов, ни кортежей, ни словарей. Поменяй names и edges — получишь МОД своего графа!
