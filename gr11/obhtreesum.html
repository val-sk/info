01 · задача

Сложить все числа в дереве

Есть дерево: у каждого узла — число и дети. Нужно побывать в каждом узле и сложить все числа.

  • 1 — корень, с него начинаем;
  • 2 и 3 — его дети;
  • 4, 5, 6, 7 — листья, детей у них нет;
  • ответ, конечно, 28 — но нас интересует маршрут: как обойти все узлы и ни один не пропустить.
Проверить ответ

1 + 2 + 3 + 4 + 5 + 6 + 7 = 28. Программа должна сама дойти до каждого узла — этим и займёмся.

02 · структура данных

Храним дерево обычным списком

Узел — это список: первым идёт число, дальше — дети. Ребёнок — такой же список. И всё, никаких классов и словарей.

tree = [1, [2, [4], [5]], [3, [6], [7]]]

■ число корня   ■ левое поддерево   ■ правое поддерево

Правило для любого узла

node[0] — число этого узла

node[1:] — список детей (каждый — тоже дерево)

Лист — список из одного числа: node[1:] пустой.

Примеры

tree[0]        # 1 — число корня
tree[1]        # [2, [4], [5]] — левый ребёнок
tree[1][0]     # 2
tree[1][1]     # [4] — лист
[4][1:]        # [] — детей нет
03 · два маршрута

Обойти = посетить каждый узел ровно один раз

Порядок можно выбрать. Классических маршрута два:

Вглубь (DFS)

Ныряем по левой ветке до листа, откатываемся, ныряем снова.
Порядок: 1 · 2 · 4 · 5 · 3 · 6 · 7

Вширь (BFS)

Сначала весь уровень, потом следующий — как волны.
Порядок: 1 · 2 · 3 · 4 · 5 · 6 · 7

Маленькая цифра у узла — номер шага, на котором его посетили. Рекурсия и стек дадут первый маршрут, очередь — второй.

04 · решение 1 — рекурсия

«Моё число + суммы детей»

def sum_rec(node):
    total = node[0]              # число этого узла
    for child in node[1:]:       # каждый ребёнок — тоже дерево
        total += sum_rec(child)  # рекурсия: спрашиваем ребёнка
    return total

print(sum_rec(tree))   # 28
  • Функция вызывает саму себя для каждого ребёнка — это и есть рекурсия.
  • Где остановка? У листа node[1:] пуст → цикл не сделает ни шага → функция просто вернёт своё число.
  • Незавершённые вызовы Python складывает в стопку — стек вызовов. Ребёнок вернул сумму — родитель продолжает с того места, где остановился.
  • Явного стека в коде нет — он спрятан внутри Python.

06 · решение 2 — явный стек

Тот же обход, но стек своими руками

Стек — стопка тарелок 🍽

Кладём и берём только с верхушки. В Python это обычный список:

stack.append(x)   # положить наверх (в конец)
stack.pop()       # снять сверху (с конца)
def sum_stack(tree):
    total = 0
    stack = [tree]          # начинаем с корня
    while stack:            # пока есть что брать
        node = stack.pop()  # берём с конца
        total += node[0]
        for child in reversed(node[1:]):
            stack.append(child)   # кладём детей
    return total

print(sum_stack(tree))   # 28
  • Словами: положи корень → пока стек не пуст: достань узел, прибавь его число, положи его детей.
  • reversed(node[1:]) — кладём детей справа налево, чтобы левый оказался на верхушке и достался первым.
  • Получается обход вглубь — тот же порядок, что у рекурсии: 1, 2, 4, 5, 3, 6, 7.
  • while + список = рекурсия без рекурсии. Мы сами ведём стопку «что делать дальше».

08 · решение 3 — очередь

Меняем одну строку — и идём вширь

Очередь — как в кассу 🧾

Новые встают в конец, обслуживаем с начала:

queue.append(x)   # встать в конец
queue.pop(0)      # взять первого (с начала)
def sum_queue(tree):
    total = 0
    queue = [tree]
    while queue:
        node = queue.pop(0)   # берём с начала!
        total += node[0]
        for child in node[1:]:
            queue.append(child)   # дети — в конец
    return total

print(sum_queue(tree))   # 28
  • Отличие от стека — pop(0) вместо pop(). Дети кладутся в обычном порядке, reversed не нужен.
  • Ребёнок не может «обогнать» тех, кто уже стоит в очереди → сначала досчитаем весь уровень, потом спустимся ниже.
  • Это обход вширь (BFS): 1, 2, 3, 4, 5, 6, 7.

pop(0) сдвигает весь список — для учёбы идеально; для огромных очередей в бою берут collections.deque.

Для суммы порядок не важен — все узлы всё равно посещены. Но для задач вроде «найти кратчайший путь» или «напечатать по уровням» очередь незаменима. А рекурсия и явный стек — близнецы: просто во втором случае стопку «что делать дальше» мы ведём сами.
