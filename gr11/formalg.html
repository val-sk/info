"Что такое алгоритм на самом деле?"

Зачем формализовать алгоритм?

Проблема: Мы интуитивно понимаем, что такое алгоритм (рецепт, инструкция), но математика требует строгого определения.

Исторический контекст:

  • 1900 г. — Давид Гильберт задает вопрос: существует ли универсальный метод решения любых математических задач?
  • 1936 г. — Алан Тьюринг, Алонзо Чёрч и Андрей Марков независимо предлагают математические модели алгоритма
  • Результат: Доказано, что некоторые задачи принципиально неразрешимы
💡 Важно: Чтобы доказать, что алгоритма НЕ существует, нужно сначала точно определить, ЧТО такое алгоритм!

🤖 Машина Тьюринга (1936)

Идея Алана Тьюринга:

Представим человека, который решает задачу на бесконечном листе бумаги в клетку:

  • 👀 Смотрит на одну клетку
  • ✏️ Может стереть или написать символ
  • ➡️ Сдвигает бумагу влево или вправо
  • 🧠 Переходит к следующему действию (зависит от того, что видит, и его "настроя")
1
0
1
1
0

↑ Головка читает/пишет и двигается

🎯 Вывод: Этого простого набора действий достаточно для решения ЛЮБЫХ вычислимых задач!

📐 Машина Тьюринга: формально

Машина Тьюринга состоит из:

Компонент Описание Аналогия
Лента Бесконечная, разделена на ячейки Бесконечный лист бумаги
Головка Читает/пишет символ, двигается L/R Карандаш и глаза
Состояния Конечное множество Q = {q₀, q₁, ...} "Настрой" или "режим работы"
Алфавит Символы: входные + пустота (⊔) Буквы и пробелы
Программа Таблица переходов: (состояние, символ) → (новое состояние, новый символ, направление) Инструкция
📝 Пример правила:
Если состояние q₀ и символ "1" → записать "0", перейти в q₁, сдвинуться вправо (R)

💭 Тезис Чёрча—Тьюринга

Всё, что может быть вычислено человеком по четким инструкциям,
может быть вычислено Машиной Тьюринга

Важные моменты:

  • 🔬 Это тезис (гипотеза), а не теорема — его нельзя доказать математически
  • ✅ За 90 лет ни одна вычислительная модель не опровергла его
  • 🚫 Если задачу нельзя решить на МТ — её нельзя решить ни на каком компьютере (ни современном, ни будущем)

✅ Что МОЖНО вычислить:

  • Арифметические операции
  • Сортировку данных
  • Поиск в базах данных
  • Игры (шахматы, го)

❌ Что НЕЛЬЗЯ вычислить:

  • Проблема остановки (остановится ли программа?)
  • Некоторые логические парадоксы
  • Задачи с бесконечным перебором

📝 Нормальные алгорифмы Маркова (1947)

Идея Андрея Маркова:

Любое вычисление — это просто переписывание текста (замена одних букв на другие).

Устройство НАМ:

  • Алфавит (набор символов)
  • Входная строка
  • Таблица правил подстановки

📋 Два типа правил:

  • Простые: α → β (заменить и продолжить)
  • Заключительные: α →· β (заменить и СТОП)

Пример алгорифма (удаление пробелов):

пробел → (пусто)

Вход: "а б в" → Выход: "абв"

💡 Отличие от МТ: Марков работает со строками целиком, Тьюринг — с отдельными ячейками ленты

️ Как работает нормальный алгорифм

Алгоритм применения НАМ:

  1. Просматриваем таблицу правил строго сверху вниз
  2. Ищем самое левое вхождение левой части правила в строку
  3. Если найдено — применяем правило:
    • Заключительное (→·) → СТОП
    • Простое (→) → возвращаемся к пункту 1
  4. Если ни одно правило не применимо → СТОП

Пример: Инверсия битов (0↔1)

0 → x
1 → y
x → 1
y → 0

Трассировка для "10":

10 → (пр.2) → y0 → (пр.1) → yx → (пр.3) → y1 → (пр.4) → 01 ✓

⚠️ Важно: После каждого простого правила возвращаемся к НАЧАЛУ таблицы!

🤖 Задание 1: Машина Тьюринга

Задача:

Сконструируйте МТ, которая складывает два числа в унарной системе.

Вход: 111+11 (означает 3 + 2)
Выход: 11111 (означает 5)
Алфавит: {1, +, ⊔} (⊔ — пустота)

Подсказка:

  1. Двигайтесь вправо, пока не найдете "+"
  2. Замените "+" на "1" (соедините числа)
  3. Продолжайте вправо до пустоты (⊔)
  4. Сделайте шаг влево и сотрите последнюю "1"
  5. Остановитесь
1
1
1
+
1
1
⊔

⏱ Время на решение: 5 минут

✅ Решение задания 1

Таблица переходов МТ:

Состояние Символ → Новое состояние → Записать → Движение
q₀ 1 q₀ 1 R
q₀ + q₁ 1 R
q₁ 1 q₁ 1 R
q₁ ⊔ q₂ ⊔ L
q₂ 1 q_stop ⊔ —

Трассировка для "111+11":

111+11 → (q₀,R) → 111+11 → ... → 111+11 (q₀ видит +)
→ (q₁,R,записать 1) → 111111 → (q₁,R) → ... → 111111⊔
→ (q₂,L) → 111111 → (q_stop,стереть) → 11111 ✓

Задание 2: Нормальный алгорифм

Задача:

Напишите НАМ, который инвертирует двоичный код (0→1, 1→0).

Вход: 10110
Выход: 01001
Алфавит: {0, 1, x, y} (x, y — вспомогательные)

⚠️ Главная сложность:

Если просто заменить 0→1, а потом 1→0, то новые единицы снова станут нулями!

❌ Неправильно:
0 → 1
1 → 0
Результат для "10": 10 → 00 → 11 (ошибка!)

💡 Подсказка:

Используйте вспомогательные символы как "буфер"

⏱ Время на решение: 5 минут

✅ Решение задания 2

Правильные правила НАМ:

0 → x
1 → y
x → 1
y → 0

Трассировка для "10":

10 → (пр.2, самое левое) → y0
→ (возврат к началу, пр.1) → yx
→ (пр.3) → y1
→ (пр.4) → 01 ✓

Почему это работает?

  • Фаза 1: Все 0→x, все 1→y (используем временные символы)
  • Фаза 2: Все x→1, все y→0 (завершаем преобразование)
💡 Ключевой принцип: После каждого простого правила возвращаемся к началу таблицы!

Задача 1: Машина Тьюринга и число 2025

Условие:

На ленте в соседних ячейках записано двоичное представление числа 2025 без ведущих нулей. Ячейки справа и слева от последовательности заполнены пустыми символами «λ». В начальный момент времени головка расположена в ближайшей справа к последовательности ячейке.

Программа работы исполнителя:

λ 0 1
q₀ λ, L, q₁
q₁ 1, L, q₂ 0, L, q₁ 1, L, q₁
q₂ λ, S, q₂

Задание: Определите результат выполнения программы. В ответе запишите получившееся число в десятичной системе счисления.

🔍 Решение:

Шаг 1: Переводим 2025 в двоичную систему:

2025 = 1024 + 512 + 256 + 128 + 64 + 32 + 8 + 1 = 11111101001₂

Шаг 2: Анализируем программу:

  • q₀, λ → λ, L, q₁: Головка сдвигается влево на последний бит (1), переходит в q₁
  • q₁, 0 → 0, L, q₁: Если видит 0 — оставляет 0, сдвигается влево
  • q₁, 1 → 1, L, q₁: Если видит 1 — оставляет 1, сдвигается влево
  • q₁, λ → 1, L, q₂: Если видит λ (слева от числа) — записывает 1, переходит в q₂
  • q₂, λ → λ, S, q₂: Стоп

Шаг 3: Программа проходит по всем битам справа налево, не изменяя их, и когда выходит за левый край — добавляет 1 слева.

Исходная лента: 11111101001
После выполнения: 111111101001 (добавили 1 слева)

Шаг 4: Переводим результат в десятичную систему:

111111101001₂ = 2¹¹ + 2¹⁰ + 2⁹ + 2⁸ + 2⁷ + 2⁶ + 2⁵ + 2³ + 2⁰
= 2048 + 1024 + 512 + 256 + 128 + 64 + 32 + 8 + 1 = 4073
✅ Ответ: 4073

🧩 Задача 2: Инверсия последовательности

Условие:

На ленте в соседних ячейках записана последовательность из 1000 символов, включающая только нули и единицы. Ячейки справа и слева от последовательности заполнены пустыми символами «λ». В начальный момент времени головка расположена в ближайшей ячейке справа от последовательности.

Программа работы исполнителя:

λ 1 0
q₀ λ L q₁
q₁ λ S q₁ 0 L q₁ 1 L q₁

После выполнения программы единиц на ленте стало вдвое больше, чем нулей. Сколько единиц содержалось в исходной последовательности?

🔍 Решение:

Шаг 1: Анализируем программу:

  • q₀, λ → λ, L, q₁: Головка сдвигается влево на последний символ последовательности
  • q₁, 0 → 1, L, q₁: Заменяет 0 на 1, сдвигается влево
  • q₁, 1 → 0, L, q₁: Заменяет 1 на 0, сдвигается влево
  • q₁, λ → λ, S, q₁: Стоп (когда выходит за левый край)

Вывод: Программа инвертирует все биты (0→1, 1→0), проходя справа налево.

Шаг 2: Составляем уравнение:

Пусть в исходной последовательности было x единиц и (1000 - x) нулей.
После инверсии: единиц стало (1000 - x), нулей стало x.
Условие: единиц вдвое больше, чем нулей → (1000 - x) = 2x

Шаг 3: Решаем уравнение:

1000 - x = 2x
1000 = 3x
x = 333.33...

⚠️ Примечание: Получается нецелое число. Вероятно, в условии опечатка и должно быть 999 символов вместо 1000.

Если 999 символов: 999 - x = 2x → 3x = 999 → x = 333
✅ Ответ: 333 (при условии 999 символов)

🧩 Задача 3: Закрепление — число 2025

📌 Условие (аналогично задаче 1):

На ленте в соседних ячейках записано двоичное представление числа 2025 без ведущих нулей. Ячейки справа и слева от последовательности заполнены пустыми символами «λ». В начальный момент времени головка расположена в ближайшей справа к последовательности ячейке.

Программа работы исполнителя:

λ 0 1
q₀ λ, L, q₁
q₁ 1, L, q₂ 0, L, q₁ 1, L, q₁
q₂ λ, S, q₂

Задание: Определите результат выполнения программы. В ответе запишите получившееся число в десятичной системе счисления.

🔍 Решение (подробная трассировка):

Исходная лента: λ 1 1 1 1 1 1 0 1 0 0 1 λ

Головка начинает на правом λ.

Такт 1: q₀, λ → λ, L, q₁ (головка на последней 1)
Такт 2: q₁, 1 → 1, L, q₁ (головка на 0)
Такт 3: q₁, 0 → 0, L, q₁ (головка на 0)
Такт 4: q₁, 0 → 0, L, q₁ (головка на 1)
Такт 5: q₁, 1 → 1, L, q₁ (головка на 0)
Такт 6: q₁, 0 → 0, L, q₁ (головка на 1)
Такт 7: q₁, 1 → 1, L, q₁ (головка на 1)
Такт 8: q₁, 1 → 1, L, q₁ (головка на 1)
Такт 9: q₁, 1 → 1, L, q₁ (головка на 1)
Такт 10: q₁, 1 → 1, L, q₁ (головка на 1)
Такт 11: q₁, 1 → 1, L, q₁ (головка на 1)
Такт 12: q₁, λ → 1, L, q₂ (записали 1 слева, головка на левом λ)
Такт 13: q₂, λ → λ, S, q₂ (СТОП)

Результат: λ 1 1 1 1 1 1 0 1 0 0 1 λ

Добавилась единица слева от исходного числа.

111111101001₂ = 4073₁₀
✅ Ответ: 4073
