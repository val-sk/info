Метод Прима:
выращиваем минимальное остовное дерево

Одно дерево растёт из стартовой вершины. Каждый шаг — самый дешёвый кабель через границу уже построенной сети. Матрица смежности, три списка и чистый Python — без классов, кортежей и словарей.

В. Г. Соловьянюк-Кротова · АНО «Павловская гимназия» · val-sk.github.io/info

● зелёные каналы — готовое МОД весом 18. По ним уже «течёт сигнал». Как оно выросло из вершины A — увидим пошагово.

Шаг 1 · Разминка

Что помним после Краскала?

Ответь вслух — затем нажми на карточку и проверь себя.

?Что такое минимальное остовное дерево?
Подграф со всеми вершинами, без циклов, с n − 1 ребром и минимальной суммой весов.
?Как работал Краскал?
Сортировал все рёбра по весу и брал лёгкие, если концы в разных компонентах. Рос лес, который сливался в одно дерево.
?Что такое матрица смежности?
Таблица n × n: в ячейке [i][j] стоит вес ребра i–j. Для неориентированного графа матрица симметрична.
?Что означает 0 в нашей матрице?
Ребра нет (все веса положительные). Отсутствие ребра не путать с ребром нулевого веса — тогда пришлось бы кодировать пропуск иначе.
?Сколько рёбер в МОД графа с 6 вершинами?
5 = n − 1. Каждое новое ребро подключает ровно одну новую вершину.
?Чем Прим будет отличаться по стратегии?
Краскал выбирает ребро из всего графа, Прим — вершину, ближайшую к уже построенному дереву. Растёт одно связное дерево, а не лес.
Сегодня тот же граф про посёлки и оптоволокно — но станция провайдера стоит в посёлке A, и сеть будет расти именно оттуда.
Шаг 2 · Идея

Дерево растёт из одной вершины

Прим не перебирает все рёбра мира. Он смотрит только на границу построенной сети и каждый раз тянет наружу самый дешёвый кабель. Для этого каждой вершине вне дерева нужен «паспорт» из трёх списков.

used[v] — в дереве?

True / False

Вершина уже подключена кабелем? Такие вершины больше не трогаем — иначе появится цикл.

best[v] — лучший мостик

вес или ∞

Самое дешёвое ребро из дерева в v. Пока пути нет — ∞. Это кандидат, а не окончательный ответ.

from_vertex[v] — откуда

вершина или −1

Из какой вершины дерева приходит лучший мостик. Когда v победит в отборе — именно это ребро войдёт в МОД.

Граница дерева после шага 2

жёлтые — кандидаты

Зелёное A–B уже в дереве. Кандидат A–C (5) погас: из B до C всего 1 — best[C] улучшился, from[C] сменился на B.

Почему жадность безопасна: ближайшее к дереву ребро пересекает разрез «дерево / остальной граф». Самое лёгкое ребро любого разреза входит в некоторое МОД — значит, выбор Прима никогда не портит оптимум.
Ключевой момент урока: best[v] может улучшаться несколько раз, пока v ждёт своей очереди. В нашей демонстрации это случится трижды: 5→1, 6→4, 9→8.
Шаг 3 · Алгоритм

Пять шагов Прима

1️⃣ Инициализация

used = False · best = ∞ · from = −1 · best[start] = 0

Дерево ещё пусто, но стартовая вершина — ближайшая к нему (расстояние 0).

2️⃣ Выбор ближайшей

Среди вершин с used = False найти v с минимальным best[v].

3️⃣ Подключение

used[v] = True; если from[v] ≠ −1, ребро (from[v], v) входит в дерево, вес добавляется к сумме.

4️⃣ Релаксация

Просмотреть строку v матрицы: для каждого соседа to вне дерева, если w < best[to], обновить best[to] и from[to] = v.

5️⃣ Повторить n раз

Подключено n вершин, набрано n − 1 ребро — МОД готово. Если у ближайшей вершины best = ∞ — граф несвязный, дерева не существует.

⚡ Сложность

Через матрицу: O(n²) — n отборов минимума циклом + n строк длины n. Выгодно для плотных графов. Краскал с сортировкой — O(E·log E), лучше для разреженных.

Состояние программы: три списка

best[v] — не ответ, а текущий лучший кандидат. Он улучшается, пока v ждёт отбора. from[v] всегда помнит, откуда пришёл кандидат.
Шаг 5 · Сравнение

Два пути к одному дереву

Рёбра МОД одни и те же, сумма одна — 18. Но порядок добавления разный: Прим растит дерево из A, Краскал собирает его из лёгких рёбер всего графа. Числа в кружках — очерёдность.

Прим: рост из A

вес 18
1·A–B(3)2·B–C(1)3·C–E(2) 4·C–D(4)5·D–F(8)

Краскал: по весу

вес 18
1·B–C(1)2·C–E(2)3·A–B(3) 4·C–D(4)5·D–F(8)
Веса различны → МОД единственное, поэтому оба алгоритма обязаны дать одинаковый набор рёбер. При равных весах наборы могут отличаться, но минимальная сумма всегда одна.

Данные: матрица смежности

Граф — список списков n × n. В ячейке — вес ребра, 0 означает «ребра нет» (все веса положительные). Граф неориентированный → матрица симметрична относительно диагонали.

данные графа
names = ["A", "B", "C", "D", "E", "F"]
n = 6

# 0 = ребра нет, веса положительные
#        A  B  C  D  E  F
matrix = [
    [    0, 3, 5, 0, 0, 0],  # A
    [    3, 0, 1, 6, 0, 0],  # B
    [    5, 1, 0, 4, 2, 0],  # C
    [    0, 6, 4, 0, 7, 8],  # D
    [    0, 0, 2, 7, 0, 9],  # E
    [    0, 0, 0, 8, 9, 0],  # F
]
🔎 Проверь себя: где в матрице ребро C–E?нажми
matrix[2][4] == 2   # C -> E
matrix[4][2] == 2   # E -> C (симметрия!)

C — индекс 2, E — индекс 4. Вес 2 записан дважды: граф неориентированный.

Никаких словарей и кортежей: матрица — обычный список списков, имена — список строк.
Шаг 6 · Код · 2 из 5

Три списка вместо словарей и классов

Состояние алгоритма — три параллельных списка длины n. Индекс = номер вершины. INF — «бесконечность», заведомо больше любого веса.

состояние
INF = 1000000000  # больше любого возможного веса

used = [False] * n        # вершина уже в дереве?
best = [INF] * n          # вес лучшего ребра из дерева в вершину
from_vertex = [-1] * n    # откуда приходит лучшее ребро

best[0] = 0  # начинаем построение с вершины A
🔎 Что лежит в best сразу после инициализации?нажми
best = [0, INF, INF, INF, INF, INF]

Только A «близка к дереву» (расстояние 0). Остальные пока недостижимы — у них нет ни одного кандидата.

Списки создаются умножением: [False] * n — n независимых значений. Для чисел и булевых это безопасно (они неизменяемые).
Шаг 6 · Код · 3 из 5

Выбор ближайшей вершины — обычным циклом

Никаких min(..., key=...) и кортежей. Ищем минимум вручную: v = −1 — «пока никого не нашли», затем перебираем только неиспользованные вершины.

выбор v (внутри цикла по n)
v = -1
for i in range(n):
    if not used[i]:
        if v == -1 or best[i] < best[v]:
            v = i
🔎 Кого выберет этот цикл после шага 1?нажми
# best = [INF, 3, 5, INF, INF, INF], used[A] = True
# i=1 (B): v=-1 -> берём B, v=1
# i=2 (C): best[C]=5 < best[B]=3? Нет -> пропускаем
# Ответ: v = 1, вершина B

Первая неиспользованная становится кандидатом благодаря проверке v == -1, дальше сравниваем веса.

Этот блок выполняется n раз — внутри for count in range(n). Каждый отбор — O(n), всего O(n²).
Шаг 6 · Код · 4 из 5

Подключаем вершину и обновляем кандидатов

Сердце Прима. Сначала фиксируем победу v, затем просматриваем строку v матрицы и улучшаем best у соседей, которым новый путь дешевле.

тело цикла (v уже выбрана)
mst = []
total = 0

# дальше — тело цикла, v уже выбрана (шаг 3)
used[v] = True

if from_vertex[v] != -1:
    mst.append([from_vertex[v], v, best[v]])
    total = total + best[v]

for to in range(n):
    w = matrix[v][to]
    if w != 0 and not used[to] and w < best[to]:
        best[to] = w
        from_vertex[to] = v
🔎 Что изменится в best после просмотра строки B?нажми
# было: best[C]=5 (from A), best[D]=INF
# строка B: до C = 1, до D = 6
best[C] = 1          # 5 -> 1, from_vertex[C] = B
best[D] = 6          # INF -> 6, from_vertex[D] = B

Три условия фильтра: w ≠ 0 (ребро есть) · not used[to] (to ещё вне дерева) · w < best[to] (стало дешевле).

Зачем not used[to]? Вершины в дереве уже подключены оптимально. Трогать их — значит «переподключать» готовую часть и рисковать циклом.
Шаг 6 · Код · 5 из 5

Выводим ответ буквами

В mst лежат рёбра-списки [from, v, вес] в порядке подключения. Индексы превращаем в имена через names, сумма уже накоплена в total.

вывод
print("Рёбра минимального остовного дерева (алгоритм Прима):")
for edge in mst:
    print(names[edge[0]], "-", names[edge[1]], "вес", edge[2])
print("Суммарный вес:", total)
Порядок рёбер в выводе — порядок роста дерева: A–B, B–C, C–E, C–D, D–F. У Краскала тот же набор выводился по весу: B–C, C–E, A–B, C–D, D–F.
Шаг 7 · Всё вместе

Полная программа

prim.py 
# Минимальное остовное дерево — алгоритм Прима
# Граф задан матрицей смежности (список списков)
# 0 означает "ребра нет" (все веса положительные)
# Только списки, циклы, условия и функции

names = ["A", "B", "C", "D", "E", "F"]
n = 6

#        A  B  C  D  E  F
matrix = [
    [    0, 3, 5, 0, 0, 0],  # A
    [    3, 0, 1, 6, 0, 0],  # B
    [    5, 1, 0, 4, 2, 0],  # C
    [    0, 6, 4, 0, 7, 8],  # D
    [    0, 0, 2, 7, 0, 9],  # E
    [    0, 0, 0, 8, 9, 0],  # F
]

INF = 1000000000  # больше любого возможного веса

used = [False] * n        # вершина уже в дереве?
best = [INF] * n          # вес лучшего ребра из дерева в вершину
from_vertex = [-1] * n    # откуда приходит лучшее ребро

best[0] = 0  # начинаем построение с вершины A

mst = []
total = 0

for count in range(n):
    # 1. Ищем вершину вне дерева с минимальным best
    v = -1
    for i in range(n):
        if not used[i]:
            if v == -1 or best[i] < best[v]:
                v = i

    # достижимых вершин не осталось — граф несвязный
    if best[v] == INF:
        print("Граф несвязный: остовное дерево не существует")
        break

    used[v] = True

    # 2. Подключаем v к дереву ребром from_vertex[v] - v
    if from_vertex[v] != -1:
        mst.append([from_vertex[v], v, best[v]])
        total = total + best[v]

    # 3. Обновляем лучшие рёбра для соседей v
    for to in range(n):
        w = matrix[v][to]
        if w != 0 and not used[to] and w < best[to]:
            best[to] = w
            from_vertex[to] = v

# Вывод результата
print("Рёбра минимального остовного дерева (алгоритм Прима):")
for edge in mst:
    print(names[edge[0]], "-", names[edge[1]], "вес", edge[2])
print("Суммарный вес:", total)

🌱 Стратегия

Прим растит одно дерево из стартовой вершины, каждый шаг добавляя ближайшую к нему вершину через самый дешёвый мостик.

📋 Три списка

used — кто в дереве, best — лучший кандидат, from_vertex — откуда он. Кандидаты улучшаются, пока вершина ждёт.

🧮 Матрица

Строка выбранной вершины — релаксация соседей. Сложность O(n²), удобно для плотных графов. 0 = ребра нет.
