Исторический факт · 1736 год

Семь мостов Кёнигсберга

Можно ли пройти по всем семи мостам города ровно по одному разу? Леонард Эйлер заменил сушу вершинами, а мосты — рёбрами, доказал, что нельзя, — и этим открыл теорию графов. Попробуйте сами: кликайте по суше, каждый мост — только один раз!

Почему невозможно?

Степени вершин: A=3, B=5, C=3, D=3 — все нечётные. Эйлер доказал: обход каждого ребра ровно один раз возможен, только если нечётных вершин 0 или 2. Здесь их четыре — прогулка невозможна. Зато родилась теория графов!

Мосты — рёбра, суша — вершины. Это первый граф в истории науки: Эйлер, 1736, Санкт-Петербургская академия.

Теория · 2 из 4

Весовая матрица

Строки и столбцы — вершины; в клетке (i, j) — вес ребра i–j. Нет ребра — ставим ∞ (или 0 по договорённости). Меняйте веса в таблице и следите за графом; наведите на клетку — ребро подсветится.

Теория · 3 из 4

Длина пути = сумма весов

Длина пути — сумма весов всех его рёбер. В невзвешенном графе каждое ребро считается за 1, и длина — просто число рёбер. Кратчайший путь — путь минимальной длины. Стройте путь кликами и сравните два режима!

Правило подсчёта

N(старт) = 1, а дальше N(v) = Σ N(u) по всем входящим дугам u→v. Вершины обрабатываем слева направо. С циклами так нельзя — путей стало бы бесконечно много!

Порядок работы

  1. Откройте Яндекс-учебник и рабочую тетрадь по теме «Графы: длина и количество путей, обоснование».
  2. Длина пути: решите задания по весовой матрице — выпишите рёбра маршрута и сумму их весов.
  3. Количество путей: для каждой вершины DAG выпишите N(v) и обоснуйте: N(v) = Σ N(u) по входящим дугам.
  4. Проверьте себя: сверьте ответ с автопроверкой; если ошиблись — найдите вершину, где N(v) посчитано неверно.

Образец обоснования

Дуги: А→Б, А→В, Б→В. Сколько путей из А в В? Так должна выглядеть запись в тетради:

N(А) = 1 — старт
N(Б) = N(А) = 1
N(В) = N(А) + N(Б) = 1 + 1 = 2
Ответ: 2 пути.
Подсказка: правило N(v) = Σ N(u) и тренажёр — на слайде «Сколько путей? Считаем в DAG».
