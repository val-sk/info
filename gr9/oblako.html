🚀 Практика: «Облачный тандем → Альянс»

📋 Этап 1. Работа в парах (10 минут)

Класс делится на две группы. Каждая пара получает свой текст из папки 9 класс\!Задания:

🔴 Группа А — «Угрозы»

Тема: Информационная безопасность: угрозы

📄 Текст: «ИБ_угрозы.txt»

🎯 Задача: выделить виды угроз и составить таблицу

🔵 Группа Б — «Защита»

Тема: Информационная безопасность: защита

📄 Текст: «ИБ_защита.txt»

🎯 Задача: выделить способы защиты и составить таблицу

клик по слайду — следующий блок

🤝 Ваши роли в паре

👷 Ученик 1 — Архитектор

  • Создает файл в своем облаке (Яндекс / Google / Apple)
  • Настраивает доступ: «По ссылке → Редактирование»
  • Отправляет ссылку партнёру
  • Создает таблицу по своей теме

🔍 Ученик 2 — Аналитик

  • Переходит по ссылке
  • Заполняет таблицу из текста
  • Выделяет заголовки цветом
  • Отправляет ссылку учителю через Моджо

📊 Формат таблицы:

🔴 Группа А: «Вид угрозы / Пример / Последствия»
🔵 Группа Б: «Угроза / Правило защиты / Инструмент»

🔗 Этап 2: «Облачный альянс»

Объединяемся в четверки! (8 минут)

Пара из Группы А + Пара из Группы Б = Четверка «Щит и Меч» 🛡⚔️

🎯 Задача четверки:

Создать ОДИН общий облачный документ «Памятка: Кибербезопасность школьника»

📑 Структура документа:

  1. 🔴 Сначала — раздел «Угрозы» (копируем таблицу от Группы А)
  2. 🔵 Затем — раздел «Защита» (копируем таблицу от Группы Б)
  3. ✨ В конце — вывод от всей четверки

👑 Роль лидера четверки: один из Архитекторов создает новый общий документ и шарит ссылку остальным троим на «Редактирование».

📋 Алгоритм работы в четверке

Шаг 1. 🔗 Обменяйтесь ссылками между парами (А ↔ Б)

Шаг 2. 📄 Лидер создает новый документ «Памятка_четверки_№__»

Шаг 3. ✏️ Открывает доступ «По ссылке → Редактирование» для троих

Шаг 4. 📋 Группа А вставляет свой раздел «Угрозы» в начало

Шаг 5. 📋 Группа Б вставляет свой раздел «Защита» ниже

Шаг 6. 💬 Все четверо добавляют по 1 комментарию с тегом @партнёр

Шаг 7. 📤 Лидер отправляет итоговую ссылку учителю через Моджо
